📡 ESP32 연결 방법

ESP32에서 아래 엔드포인트로 POST 요청을 전송합니다:

POST http://[서버IP]:5050/mes/count
Content-Type: application/json

{
  "device_id": "ESP32_LINE_A",
  "count": 1234,
  "token": "{{ mes_token or '(MES_TOKEN 미설정)' }}"
}

Arduino 예시 코드:

HTTPClient http;
http.begin("http://[서버IP]:5050/mes/count");
http.addHeader("Content-Type", "application/json");
String body = "{\"device_id\":\"ESP32_LINE_A\",\"count\":" + String(labelCount) + "}";
int code = http.POST(body);
http.end();
토큰 설정: 서버 .env에 MES_TOKEN=your_secret 추가 후 재배포
