🔌ERP API 테스트
영림원 ERP [Ksystem API 등록] 화면에 공개한 API 를 여기서 직접 호출해 본다. 인증정보는 서버 .env 에서 읽으므로 화면에 입력하지 않는다.
SP 방식은 SP 공개설정 그리드의 호출ID, 서비스 방식은 서비스 공개설정 그리드의 OpenApi명을 넣는다.
호출 방식
호출ID / OpenApi명
URL 세그먼트
서비스 방식의 정확한 세그먼트가 확인되면 고정한다. 실패 시 이 값을 바꿔 시험한다.
userId (선택)
DataBlock (JSON)
빠른 입력
결과 대기
호출하면 여기에 요청·응답이 표시된다.
