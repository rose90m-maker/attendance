🔄 데이터 수집 배치 안내

Docker 컨테이너 내부에서 15분마다 자동 수집하려면 크론탭을 설정하세요:

*/15 * * * * docker exec attendance-app python /app/kepco_collector.py today

수동 수집:

# 오늘 데이터
docker exec attendance-app python /app/kepco_collector.py today

# 기간 수집 (YYYYMMDD 형식)
docker exec attendance-app python /app/kepco_collector.py range 20250401 20250414

# DB 테이블만 초기화
docker exec attendance-app python /app/kepco_collector.py init_db
